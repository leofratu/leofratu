## Building Dwelon

I'm building **Dwelon**, an agentic property management platform. The core product lives in private repositories. My public work explores AI agents, learning tools, and experiments in finance and health.

## Selected projects

### [Noot Study](https://github.com/leofratu/nootstudy)

**Native macOS study workspace · SwiftUI / SwiftData**

Flashcards, quizzes, practice exams, and spaced review in one app. ARIA connects to configurable AI providers for tutoring, generation, and marking. Saved-card practice and scheduled review work without an AI connection.

### [Muse Classic](https://github.com/leofratu/muse-tracker)

**Local EEG workstation · Python / JavaScript**

Four-channel live waveforms, Welch spectra, band powers, labelled references, and raw recordings for Muse headsets. Designed for exploratory signal analysis, with explicit signal checks and local JSONL/CSV exports.

### [deslopify](https://github.com/leofratu/deslopify)

**Writing tools for developers and agents · Python**

A library, CLI, MCP server, and agent skill for spotting formulaic prose, rewriting it, and comparing before/after scores. The analyzer works offline; LLM rewriting uses a configured API.

### [Label Loop](https://github.com/leofratu/oai-hackathon)

**Browser-based active learning · JavaScript / WebMCP**

A support-ticket classifier that learns from human-confirmed labels. Browser agents can rank uncertain examples, request review, evaluate the model, and propose settings. People retain control over labels and approvals.
